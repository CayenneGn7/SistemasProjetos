# Sistema de Gerenciamento de Projetos

Projeto desenvolvido em Java com o objetivo de cadastrar, listar, buscar e remover projetos, aplicando conceitos de programação orientada a objetos e coleções.

## Funcionalidades

- Cadastro de projetos.
- Listagem de projetos cadastrados.
- Busca por ID.
- Busca por categoria.
- Busca por status.
- Remoção de projetos por ID.
- Validação de nome vazio e ID duplicado.

## Tecnologias utilizadas

- Java
- Git
- GitHub

## Estrutura do projeto

```text
src/
├── Main.java
├── ExemploLista.java
├── model/
│   └── Projeto.java
└── service/
    └── ProjetoService.java
```

## Execução

Compile os arquivos Java a partir da pasta `src`:

```bash
javac Main.java model/Projeto.java service/ProjetoService.java
```

Execute o programa:

```bash
java Main
```
